# 🕷️ Web Scraper

A powerful and flexible **web scraping tool** built with **Node.js** to automate data extraction from websites. Designed for easy configuration and extensibility, this scraper can help you gather data for research, monitoring, or business intelligence.

Here's the link of that website (https://www.cars.com)

## 🚀 Features

- ✅ Supports scraping of dynamic and static web pages  
- 🔄 Handles pagination and multi-page scraping  
- ⏳ Configurable delays and retries to avoid blocks  
- 📄 Saves scraped data in JSON or CSV format  
- 🧩 Easy to customize selectors for targeted data  
- 🛠️ Built with Puppeteer and Axios for flexibility

---

## 🛠️ Tech Stack

| Technology | Purpose                        |
|------------|--------------------------------|
| Node.js    | Runtime environment            |
| Puppeteer  | Headless browser automation    |
| Axios      | HTTP requests                  |
| Cheerio    | HTML parsing and querying      |
| fs         | File system interaction        |
